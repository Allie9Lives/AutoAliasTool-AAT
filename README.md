 Gmail Auto-Alias Tool (AAT)

A Tampermonkey userscript that automatically fills site-specific Gmail aliases on web forms and highlights which alias received an email directly inside Gmail.

Features:
* **Auto-Fill Aliases:** Double-click any email input on any website to insert a site-specific alias (e.g., `user+netflix@gmail.com`).
* **Gmail Visualizer:** Displays a prominent badge in Gmail showing which alias received the email (e.g., `Sent to Alias: netflix`).
* **Real-time Updates:** Works dynamically with live inbox updates.

## Quick Installation
1. Install the [Tampermonkey Extension](https://www.tampermonkey.net/) for your browser.
2. Click the button below to install the script:
   
 **[Click Here to Install Script](https://github.com/Allie9Lives/AutoAliasTool-AAT/releases/latest/download/gmail-alias-manager.user.js)**

## Configuration
1. After installation, open any site with an email field.
2. Enter your base Gmail address when prompted (e.g., `yourname@gmail.com`).
3. To update your address later, click the Tampermonkey icon in your toolbar and select **"Set Base Gmail Address"**.
